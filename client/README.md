# Patent Reviewer UI

## Layout

Application code is in the `src/` directory.

```
src
├── App.tsx # Main App Shell
├── Document.tsx # Document editor component
├── Editor.tsx # Tiptap Editor
├── components/ # Shared presentational components (Spinner)
├── test/ # Vitest setup
├── main.tsx
```

## Running locally

To run locally,

```sh
npm install
npm run dev
```
